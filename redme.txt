               RESUMEN DE AVANCE – PROYECTO ZIPPERS PERÚ
====================================================================

DESCRIPCIÓN:
Sistema automatizado de ventas retail enfocado en transformar 
mercados y consolidar a ZIPPERS como una marca líder de estilo 
de vida urbano. El sistema gestiona exclusivamente flujos de 
productos terminados y logística rápida.

ESTADO ACTUAL: Avance Fase 1 (Mockups y Seguridad Básica)
ARQUITECTURA: SPA (Single Page Application) - Cero recargas de URL.
DISEÑO UI: Dashboard administrativo con Sidebar lateral izquierdo.

1. BASE DEL PROYECTO
Stack: Spring Boot 3.5.14, Java 21, MySQL 8.0, Thymeleaf, Bootstrap 5, Lombok 1.18.38.
Estructura: Paquete base com.zippers.sistema_ventas, con subpaquetes config, controller, entity, repository, service.
Base de datos: bd_zippers con todas las tablas del modelo relacional.
Credenciales de prueba: joel.davila@zippers.pe / admin123 (BCrypt)

4. ERRORES SOLUCIONADOS DURANTE EL DESARROLLO

Lombok no generaba getters/setters: se actualizó a 1.18.38 y se configuró maven-compiler-plugin con annotationProcessorPaths.
TypeTag UNKNOWN al compilar: se fijó la versión del compilador a 3.13.0.
PermisoRepository no encontraba idRol: se escribieron consultas JPQL explícitas.
Ruta /perfiles ambigua: se eliminó el método en WebController.
403 Forbidden en AJAX: se deshabilitó CSRF para simplificar.
Advertencias de nulabilidad: se añadieron comprobaciones if (p != null) y if (rol == null).
Error setPermiso_leer / setPermiso_exportar undefined: se necesita actualizar Permiso.java con los nuevos campos (siguiente paso).
